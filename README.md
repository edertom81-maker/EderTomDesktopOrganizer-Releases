# Eder Tom Desktop Organizer – Releases

Dieses Repository stellt die signierten Installations- und Updatepakete für den **Eder Tom Desktop Organizer** bereit.

Die Anwendung prüft diesen Release-Kanal optional beim Start und jederzeit manuell. Updates werden erst nach ausdrücklicher Bestätigung heruntergeladen und installiert.
